Admin

GitHub login

Only the Fansware account sees this panel. GitHub Pages cannot hide an OAuth client secret, so login uses a Personal Access Token (fine-grained or classic) with contents:write on Fansware/something2.

Create token: GitHub → Settings → Developer settings → Personal access tokens.
Repo access: Fansware/something2 · Contents: Read and write.
Token stays in this browser only (localStorage). It is not sent to any server of ours.
